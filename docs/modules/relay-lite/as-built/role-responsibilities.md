# 角色职责与完整路径（RLT_37）

核心入口skill/SKILL.md规定角色与路由，references/decision-guide.md承载输入、决定内容、消费和10个场景；两adapter派单模板带原目标、授权/预算/停止线及后续去向。tools/install_skill.py将指南列入受管闭集，独立临时home测试覆盖六副本及缺指南前置拒绝。

正常步骤直接推进；编排识别偏离并交顾问；decider授权内决定、授权外准备建议；执行者产证、复核者独立判定。无新增角色/账本/运行策略引擎，不扩大任何真实业务授权。

验证边界：协议推演与分发测试，不是实际业务会话效果测量；源码交付不代表真实用户安装副本已更新。最终独立复核/CI/合入证据以workspace/37-RLT_37-role-responsibilities为准。

## RLT_39 · 主编排持续推进

共用references/orchestration.md承载结果后下一步、BLOCKED解阻、插问后续做、真正停点四项职责；核心入口短提示，decision-guide给正反例，watcher等待异常回链解阻。两adapter沿既有必读路由消费同一份合同。

worker signal后仍立即停止；编排按既有派单/模型/计数路由后续，不代跑测试或代判；decider只在需要路线判断时介入。等待受阻动作时继续无依赖的授权内工作；无可推进工作才说明具体解除条件及下一责任方。

验证边界仍为协议推演与安装消费者测试，不等于真实Codex/Claude行为实测；双设备实际安装以独立部署审计为准。RLT_39证据见workspace/39-RLT_39-proactive-orchestration。
