# RLT_37 施工方协议场景推演

这是对提示协议的静态推演，不是启动业务agent的行为测量，也不证明真实审批次数下降。入口为skill/SKILL.md→decision-guide及两adapter模板。最终fresh reviewer须独立判断这些场景。

| 场景 | 输入事实 | 按当前协议导出的处理 | 结论 |
|---|---|---|---|
| S1 正常推进 | 全程授权、下一步骤明确、结果符合预期 | 编排核结果并继续，不派decider或问用户 | 符合RL37-M3 |
| S2 卡内选路 | 兼容实现A/B均在允许路径、预算足够 | decider比较并交完整后续路径；知会后派执行者，复核不省略 | 符合RL37-M1/M2 |
| S3 窄授权 | 仅构建一次，已成功且要求停止 | 先停；顾问准备复现/修复/复测/收束资源与预算建议和剩余审批点，集中请用户决定 | 符合RL37-M2/M3/M4 |
| S4 有效RED | 产品未修复，现有授权含修复/复测 | 沿已有合同进入修复；RED不等于任务完成 | 符合RL37-M3 |
| S5 重复失败 | 两次同类准备失败已明确，额度不可清零 | 带历史回decider重审方法及替代路线；额度不足停依赖动作 | 符合RL37-M4 |
| S6 普通纠错 | 参数错误、修复类型及剩余额度已明确 | executor修复并验证，无需新增决策审批 | 符合RL37-M3/M4 |
| S7 新资源/验收 | 需外部数据库或放宽结果标准 | 研究已有证据与备选方案后提交用户，不能试连或代验收 | 符合RL37-M2/M4 |
| S8 未知 | 实例身份或动作结果未知 | 停受影响动作，保存证据，不自动重试/清理；顾问不代取证 | 符合RL37-M4 |
| S9 紧急 | 已触发既定安全停止条件 | 不等顾问/攒齐，立即停止新动作并报告，仅已授权处置 | 符合RL37-M4 |
| S10 独立分支 | A待用户裁决，B无依赖且已授权 | 暂停A依赖动作，继续B | 符合RL37-M2/M3 |

边界核对：原六类方向问题、RELAY_RECEIPT、未知不重试、模型确认、signal闭集、写者权限和复核配方未扩大。新增指南进入安装闭集，有独立目标文件与引用可达测试；不能只凭关键词证明以上推演。
